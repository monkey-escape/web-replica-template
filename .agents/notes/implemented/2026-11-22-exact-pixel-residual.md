# 精确像素残差作为证据，不收严 pixelThreshold

评估了把默认 `pixelThreshold` 从 `0.1` 收严。用肽站试跑已有的 actual / baseline 对照后，认为这不是有效优化，因此没有改默认阈值。

- 阈值 `0`：各页有约 7.5%–35.9% 的精确像素差，多半是抗锯齿和细微色偏。循环会在不可维护的噪声里打转。
- 阈值 `0.05` 和 `0.1`：这组图全部为 0 个感知差异，判定不变，没有提高结果质量。
- 阈值 `0.03`：会在首页桌面等页报 3–274 个差异，但这些点铺在整页（每个 16×16 格子里大约一个点），不是成片缺陷。strict 下 3 个像素也会失败，容易误导模型。

有效改动：比对时额外记录阈值 `0` 的 `exactMismatched` / `exactRatio`，写入 `report.exactPixel`。感知比对仍按 `0.1` 决定是否通过；精确残差达到 1% 时，`brief` 写 `exact_residual`，不挡 `ready_for_review`。另外，测量已完成但尚未跑视觉时，`stage` 回落为 `visual`，不再误标成 `gates`。
