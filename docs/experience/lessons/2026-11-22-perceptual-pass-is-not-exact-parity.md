# 感知比对通过不等于精确像素 1:1

- date: 2026-11-22

`pixelThreshold` 默认 0.1 是 pixelmatch 的逐像素 YIQ 灵敏度，不是差异比例。感知阈值下 mismatches 为 0，只说明按该灵敏度没有被计为差异的像素，并不表示 PNG 逐像素一致，也不表示文件哈希相同。

同一组参考图与实际图，感知阈值 0.1 可以全部通过，精确阈值 0 仍可能留下大面积残差（本轮最高约 35%）。把阈值收到 0.05 往往和 0.1 得出同一结论；收到 0.03 或 0 会把抗锯齿噪声或分散的单个像素当成失败，不能当作有效的质量门禁。

文件 SHA 不同、解码尺寸相同，是常见现象。`ready_for_review` 仍可成立，但 brief 应带上 `exact_residual=...`。不要把感知通过说成「像素差为 0」或「已经 1:1 对齐」。
